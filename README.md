# てのひら 🤲
### 障害者向け生活支援WEBアプリ

> **Repository**: https://github.com/kumadon-ai/tenohira-app

音声操作・カメラAI解析・GPS位置情報を組み合わせた、ハンディキャップ者向けの生活支援WEBアプリです。

## 使い方

1. `accessibility-support-app.html` をブラウザで開く
2. 位置情報・マイク・カメラの許可を承認
3. マイクボタンまたは画面ボタンで操作

## 対応ブラウザ

- Chrome（推奨）
- Safari（iOS）
- Edge
